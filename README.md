#PDF Cleaner v1.2
Source code developed with AI assistance, manually debugged, tested and maintained.

Introduction
PDF Cleaner is a lightweight desktop GUI tool for cleaning and optimizing PDF files.
It supports drag-and-drop PDF processing, can remove redundant objects, clean metadata, compress PDF and perform other PDF cleanup operations, powered by `pikepdf`.

  Features
- Graphical interface, no command-line operation required
- Drag and drop PDF files directly
- Clean PDF metadata (author, title, comment, hidden information etc.)
- Remove redundant internal objects in PDF
- Optimize and shrink PDF file size
- Export cleaned new PDF to local disk

Dependencies
- Python 3.10+
- pikepdf (Apache-2.0 License)
- tkinterdnd2 (MIT License)
- tkinter (Built-in Python GUI library)

 Build Instruction
 1. Install required packages
powershell
python -m pip install -U pikepdf tkinterdnd2
